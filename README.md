# SMO Calculator

Windows-приложение для расчёта характеристик систем массового обслуживания (СМО). На вход подаются интенсивность потока заявок, интенсивность обслуживания, число каналов и другие параметры — на выходе рассчитываются вероятностные и временные характеристики системы.

# Поддерживаемые модели
- одноканальная система с отказами
- многоканальная система с отказами
- многоканальная система с ограниченной очередью
- многоканальная система с ожиданием
- многоканальная система с ограниченным временем ожидания

# Рассчитываемые характеристики

В зависимости от выбранной модели вычисляются:
Показатель	                                           |      Описание

Интенсивность нагрузки	                               |   Отношение интенсивности заявок к интенсивности обслуживания

Вероятность простоя системы	                           |   Вероятность отсутствия заявок в системе

Вероятность отказа                        	           |   Вероятность отказа в обслуживании заявки

Относительная и абсолютная пропускная способность	     |   Доля и число обслуженных заявок в единицу времени

Среднее число занятых каналов	                         |   Загрузка обслуживающих каналов

Среднее число заявок в очереди и в системе	           |   Показатели загрузки очереди

Среднее время пребывания заявки	                       |   В очереди, на обслуживании и в системе в целом

# Реализация

Приложение написано на C# (Windows Forms). Формулы для стационарных вероятностей состояний и характеристик СМО реализованы отдельными методами для каждого типа модели; для моделей с очередью используется рекуррентный расчёт вероятностей по числу каналов и длине очереди.

# Запуск

Запускается исполняемый файл SMO.exe — установка не требуется. В интерфейсе указываются параметры системы (λ, μ, число каналов, длина очереди при необходимости), выбирается тип модели, после чего по кнопке расчёта выводятся характеристики и таблица распределения вероятностей.
